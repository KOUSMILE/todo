# 思考のかけら（哲学探索ゲーム・プロトタイプ）

`game/index.html` をブラウザで開けば遊べます（ビルド不要・依存なし）。

## ゲームの流れ

1. **探索** — 場所の中のものを調べると「思考のピース」が手に入る
2. **合成** — 2つのピースを組み合わせると、より深い考え（✦ 合成ピース）が生まれる
3. **問い** — 各場所の人物が問いを投げかける。ピースを置いて答える
   - 正解はひとつではなく、置いたピースによって **立場**（イデア論者・懐疑論者・実存主義者 など）が変わる
   - 答えると新しい場所が開く。2回失敗するとヒントが出る
4. **問いの塔** — 最後に3つのピースで「あなたは誰か」に答え、旅で選んだ立場がまとめられる

進行状況はブラウザの localStorage に保存されます。

## 内容の追加方法

内容はすべて `data.js` にあり、エンジン（`game.js`）を触らずに増やせます。

| 定数 | 役割 |
| --- | --- |
| `PIECES` | ピース（`kind: 'base'` は探索で入手、`'synth'` は合成で生まれる） |
| `RECIPES` | 合成レシピ（順不同の2ピース → 1ピース） |
| `LOCATIONS` | 場所・調べられるもの・その場所の問い |
| `QUESTIONS` | 問い。`answers` は上から順に判定し、`requires` のピースがすべて置かれていれば成立 |
| `TOWER_REQUIRES` | 最終地点が開く条件 |

## 今後のアイデア

- ピースに「属性」（存在論・認識論・倫理など）を付け、属性の組み合わせで答えを判定する
- 同じ問いに矛盾する立場で答えると、人物同士が議論を始める
- 立場の履歴によってエンディングが分岐する
